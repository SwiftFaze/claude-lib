# Uncle Bob Craft

Skill for applying Robert C. Martin (Uncle Bob) criteria to **code review and production**: Clean Code, Clean Architecture, The Clean Coder, Clean Agile, code smells and heuristics, and design-pattern discipline.

## Contents

- **[SKILL.md](./SKILL.md)** — Main skill: when to use, overview, aggregators, design patterns, smells, review vs production, examples, limitations. Start here.
- **[reference.md](./reference.md)** — Expanded reference: Clean Architecture, The Clean Coder, Clean Agile, smells/heuristics (including the real Clean Code argument-count guidance), design patterns, scope and attribution.

These two files are the complete skill — no separate deep-reference folder
or companion skill to consult beyond them.

Use with `/devflow:uncle-bob-craft`. Does not replace the project linter, formatter, or the mechanical constraints in `.claude/workflow.md` ("Constraints").
